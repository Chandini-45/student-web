About My Pro

My Pro is a simple education portal designed to bring student and faculty resources together in one clean, responsive interface.

  • ✓ Student-focused navigation
  • ✓ Faculty information access
  • ✓ Responsive desktop and mobile UI
  • ✓ Light and dark themes
  • ✓ Browser-based local data storage

How it works

Choose Home or Services, open any option, and use the actions shown in the content panel. The Admin area lets you add portal items locally in this browser.
